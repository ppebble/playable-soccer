# Playable Soccer

Independent B42 prototype. Namespace runtime globals PS_/PSCore/PSServer/PSClient and items PlayableSoccer. Upstream game and Workshop files are read-only. No upstream code/assets copied. Existing sibling mods, saves and server presets must remain unchanged. Server owns ball simulation and validates intents; inventory conversion uses native B42 timed-action completion. Sports balls are not consumed by practice. Never publish without explicit instruction. Report Kahlua/source checks, installed hashes and actual gameplay separately.

Scope: reversible soccer-ball conversion, explicit practice start/end, ground/lob charge kick, persistent ball, friction/gravity/bounce, repeated wall collision, two user-placed goals, two teams, server scoring and central restart. No automatic age/bounce deletion, AI, offside/fouls or upstream method overrides. Session persistence means the running server session; save/restart recovery is separate. Keep all camera projection/input adaptation behind PSProjection for future Viewpoint support; do not claim Viewpoint compatibility before runtime validation.
