# Playable Soccer

Project Zomboid B42.21+용 길거리 축구 개발 버전입니다. 공을 소모하지 않고 계속 차며, 직접 지정한 두 골문으로 득점할 수 있습니다.

## 조작

1. 기본 `Base.SoccerBall`을 인벤토리에서 우클릭하여 **스포츠용 축구공으로 전환**합니다. 전용 타입은 `PlayableSoccer.SportsSoccerBall`입니다. 상태·즐겨찾기·사용자 이름·메타데이터를 유지하며 역전환도 가능합니다.
2. 스포츠 공을 주 인벤토리에 넣고 우클릭합니다. **자유 연습**은 바로 공을 차고, **경기 만들기**는 골대 두 줄을 지정한 뒤 자동으로 시작합니다. **진행 중인 경기 참가**에서는 근처 경기와 팀을 선택합니다. 3D 바닥 아이템 표시 옵션이 켜져 있어야 합니다.
3. **좌클릭: 패스/슛**(80% 미만 땅볼, 80%부터 살짝 뜨는 슛), **우클릭: 높은 로빙**(짧게 눌러도 뜸). 커서 방향으로 차며 충전량이 힘을 정합니다. 상단 중앙에 바닐라 UI 진행바 방식의 킥 게이지를 표시합니다. 대기 중에는 빈 게이지, 충전 중에는 킥 종류와 백분율을 보여줍니다. 0.45초에 100%가 되어 금색으로 바뀌며 더 오래 눌러도 세기가 증가하지 않습니다. 90% 충전(약 0.405초)부터는 강한 킥 모션으로 구분합니다. 최대 이동거리는 평지에서 좌클릭 약 24칸, 로빙 약 28칸입니다(바운스와 마지막 구름 포함).
4. **Esc**는 충전 중에는 충전 취소, 그 외에는 작은 **축구 메뉴**를 엽니다. 계속하기, 팀 변경, 조작 나가기와 소유자 전용 공 복귀·골대 재지정·종료를 제공합니다. 메뉴에서 Esc를 다시 누르면 계속합니다. 축구에서 나간 뒤의 Esc는 기본 게임 메뉴를 엽니다. 멀티플레이에서는 축구 메뉴를 열어도 경기는 멈추지 않습니다.
5. 월드 우클릭 메뉴에서 근처 공으로 다시 플레이하거나 소유자가 자신의 연습을 종료할 수 있습니다. 다른 플레이어도 같은 공을 찰 수 있습니다.

축구 조작에 참여한 플레이어가 느리게 굴러가는 지면 공에 0.8칸 이내로 접근하면 서버가 한 명에게 공 소유를 부여합니다. 공은 이동 방향의 약 0.55칸 앞을 향해 굴러갑니다. 추적 속도는 이동 속도와 뒤처진 거리에 따라 16~32칸/초 범위에서 조정합니다. 일시적으로 2칸 이상 뒤처지면 최대 0.75초 동안 따라잡을 기회를 주며, 6칸 이상 벌어지거나 지속적으로 뒤처지면 소유를 해제합니다. 벽 앞에서는 공을 발밑으로 당기되, 실제로 벽이 공과 캐릭터를 가르면 통과시키지 않고 짧은 유예 뒤 놓습니다. 축구 메뉴를 열거나 조작에서 나가면 소유를 놓습니다. 커서가 인벤토리 등 UI 위를 지나가는 것만으로는 소유를 놓지 않으며, UI 위 킥·태클 입력은 계속 차단합니다. 높은 공·빠른 슛은 자동으로 붙잡지 않으며, 주변 일반 플레이어는 자동 소유 대상이 아닙니다.

**Space는 축구 조작 중 태클**입니다. 가까운 상대 공을 커서로 가리키고 누르세요. 누르면 성공 여부와 관계없이 약 0.5초 동안 짧은 어깨 태클 시도 모션을 재생합니다. 기본 게임의 달리기 어깨 충돌 클립을 별도의 이벤트 없는 동작으로 참조하며 상체에만 적용합니다. 걷기·달리기는 이어갈 수 있고, 모션 중에는 킥 충전을 잠깐 막습니다. 태클 판정은 기존처럼 입력 즉시 서버에서 처리하며 재사용 대기시간은 유지합니다. 캐릭터 좌표를 강제로 앞으로 이동시키지는 않습니다. 약 1.4칸 이내, 전방 범위와 시야가 확보되어야 성공하며 성공·실패 모두 0.8초 재사용 대기시간이 있습니다. 같은 팀에게는 태클하지 않습니다. 성공하면 상대 소유를 해제하고 짧은 회복 시간을 부여합니다. 서 있거나 이동 중인 피해자에게는 기본 게임의 뒤로 넘어짐 → 일어서기 상태를 요청합니다. 등반·차량·다른 피격 상태에는 넘어짐을 덧씌우지 않습니다. 모드가 체력 피해나 장비 떨어뜨리기를 호출하지는 않습니다. 공이 충분히 가까우면 태클한 선수가 소유하고, 아니면 자유 공을 다시 획득합니다. 좌·우클릭 킥은 소유한 공 또는 가까운 자유 공에 사용하며 상대 소유 공을 직접 차지는 못합니다. 슛 직후에는 재획득 유예 시간을 둡니다.

축구에서 나가면 기존 밀기 입력으로 돌아갑니다. 게임 키 설정이나 전역 조작 함수를 바꾸지 않습니다. 헤딩·손으로 공 운반·태클 피해량·부상 판정은 없습니다.

## 골문과 경기

스포츠 공 우클릭 → **경기 만들기**를 선택하면 골대 지정으로 바로 들어갑니다. 기존 연습이나 경기에서는 Esc → **골대 두 줄 지정**으로 시작합니다. 차례로 1번 골대 선의 시작·끝, 2번 골대 선의 시작·끝을 클릭합니다. 총 네 번 클릭하며 첫 점 이후 선과 길이를 미리 표시합니다. 중앙 재개 지점은 두 골대 선의 중점 사이로 자동 결정됩니다. 서버가 배치를 확인하면 중앙에 공을 놓고 A팀으로 자동 참가합니다. 잘못된 배치는 설정 화면에서 다시 지정합니다. 배치 중 우클릭/Esc로 취소하면 해당 공으로 자유 연습 또는 기존 경기를 계속할 수 있습니다.

- 골문 너비 2~10칸. 서로 마주보는 두 골문을 지정하고 중앙은 각 골문 안쪽으로 최소 2칸 이상 둡니다. 모든 지정점은 소유자 40칸 이내의 로딩된 빈 바닥이어야 합니다.
- 골문은 색상별 지면 선과 기둥 표식으로 보입니다. 현재는 투영된 표시이며 실물 골대·그물 모델은 없습니다.
- 팀 선택은 경기 참가 메뉴 또는 경기 중 Esc 메뉴에서 합니다. 팀을 선택하면 공 조작으로 돌아갑니다. A 골문을 통과하면 B팀 득점, 반대도 동일합니다.
- 점수판과 골 메시지는 **화면 상단 중앙**에 표시합니다. 공 전체가 경기장 쪽에서 골문 너비·높이 안으로 넘어가야 득점합니다. 높이 제한은 .8층 단위입니다.
- 득점 후 2초간 멈췄다가 **같은 공**을 중앙으로 돌려 재개합니다. 소유자의 공 복귀 메뉴도 있습니다. 자유 연습에서는 처음 공을 만든 위치로, 경기에서는 두 골대 사이 중앙으로 복귀합니다. 공 복귀는 점수를 초기화하지 않습니다. 골문 재지정은 새 경기로 점수를 초기화합니다.
- 벽에 맞아도 계속 플레이합니다. 오프사이드·파울·스로인·AI 골키퍼는 없습니다. 팀 명단은 간단한 소속 정보이며 인원 균형이나 포지션을 강제하지 않습니다.

## 혼자 하는 소유·태클 테스트

경기를 만들거나 골대를 재지정하면 중앙 지점 양옆 약 4칸에 반지름 0.9칸의 테스트 구역 두 개를 자동 생성합니다. 구역은 지면 테두리와 이름으로 표시하며 실제 NPC나 아이템을 생성하지 않습니다. 빈 바닥과 접근 경로가 없는 구역은 생략하고 안내합니다.

1. **주황색 태클 구역:** 공을 소유한 채 캐릭터가 들어가면 태클당해 공을 잃습니다. 혼자서 피격과 재획득을 확인할 수 있습니다.
2. **파란색 상대 소유 구역:** 공을 차 넣으면 가상 상대가 낮은 공을 그 위치에서 붙잡습니다. 가까이 가서 공을 향해 **Space**를 누르면 소유를 빼앗을 수 있습니다. 높은 로빙이 구역 위를 지나가는 것만으로는 잡지 않습니다.

테스트 구역은 현재 개발 버전 경기에서 활성화되므로 실제 다인 경기에도 영향을 줍니다. 자유 연습에는 생성하지 않습니다. 상단 게이지 아래에는 자유 공·플레이어 소유·가상 상대 소유 상태가 표시됩니다.

## 공과 표시

공은 수명·바운스 횟수·정지·소유자 연결 해제로 사라지지 않습니다. 마찰과 충돌 감쇠로 멈춘 후 다시 찰 수 있습니다. 좌클릭 거리는 충전량에 따라 약 1.5~23.9칸으로 선형 증가합니다. 우클릭은 약 0.65칸에서 시작해 초반에는 더 짧고, 최대 충전에서 약 28칸에 도달합니다. 로빙 높이는 이전보다 15% 낮춰 첫 정점이 최소 약 1.8m~최대 약 9.2m이며, 최대 좌클릭은 약 0.45m만 뜹니다. 전체 궤적에는 기존의 1.4배 진행 배율을 유지합니다. 공중에서는 전진 속도를 유지하므로 첫 낙하와 두 번째 이후 바운스에서도 앞쪽으로 움직입니다. 바운스가 끝나 바닥에 굴러갈 때 마찰로 멈춥니다. 전체 비행·바운스 시간을 고려해 출발 속도를 정하므로 충전량별 총 거리는 유지합니다. 벽에 반사됐다면 반사된 방향을 따릅니다. 벽에 부딪히면 더 짧아지며, 다시 차면 새로운 킥으로 취급합니다. 최대 서버 32개/소유자 1개 연습 공을 허용하며 연습 중 해당 아이템 역전환을 막습니다.

서버가 공 물리와 득점·아이템 검증을 소유합니다. 3D 공은 새 표시 전용 아이템의 분리된 `IsoWorldInventoryObject`로 그리며 월드/타일 목록·저장·줍기 대상으로 등록하지 않습니다. 기본 축구공 모델을 참조하며 Throwing Weapons 코드나 자산을 포함하지 않습니다. 이동 거리에 따라 수직축으로 모델을 회전하고 멈추면 회전도 멈춥니다. 기본 모델의 바닥 기준 회전축으로 앞구르기할 때 공 중심이 흔들리는 문제를 피하기 위한 시각적 회전이며, 물리적으로 정확한 구름 회전은 아닙니다. 그림자는 공중에서만 작고 옅게 표시하고 착지하면 없앱니다. 회전은 네이티브 렌더 캐시의 무한 증가를 피하도록 제한된 각도 단계로 그립니다.

킥에는 전투 이벤트가 없는 별도 애니메이션 노드가 적용됩니다. 90% 미만은 기존의 다리 중심 발동작을 유지하고, 90% 이상은 강하게 내딛는 기본 클립에 상체와 다리 마스크를 적용합니다. 좌·우클릭 모두 서버가 승인한 충전량으로 모션을 선택합니다. **기본 발동작을 조합한 구현이며 새로 제작한 전방 축구 킥은 아닙니다.** 캐릭터 이동은 잠그지 않습니다. 발 접촉과 공 출발의 정밀 일치·원격 재생은 실기 확인이 필요합니다. 어깨 태클 역시 기본 클립을 상체에 조합한 구현이며, 앞서 만든 이미지 시안과 동일한 새 3D 애니메이션을 제작한 것은 아닙니다. 실제 자세와 원격 화면의 재생은 게임에서 확인해야 합니다.

## Viewpoint 준비 및 한계

골문과 물리는 월드 좌표로 저장합니다. 모든 클릭/화면 투영은 `PSProjection` 연결부를 통하며 추후 카메라 어댑터로 교체할 수 있습니다. **현재 Viewpoint 호환은 활성화하지 않았습니다.** Viewpoint가 감지되고 어댑터가 없으면 잘못된 좌표로 차거나 배치하지 않도록 해당 입력을 막습니다. 이후 마우스 레이캐스트, 층/높이, 3D 공·표식 렌더 순서, HUD 및 우클릭 충돌을 함께 검증해야 합니다. 좌표 함수만 연결했다고 호환 완료로 간주하지 않습니다.

유지 범위는 현재 서버 실행 세션이며 저장/재시작 후 공 위치 복원은 없습니다. 벽·닫힌 문/창문·고체 타일은 보수적으로 충돌하며 정밀 가구/차량/공 반지름 충돌, 천장, 공중 층 이동은 아직 없습니다. 로딩 안 된 지역과 바닥 없는 곳 앞에서는 정지합니다. 로빙은 열린 공간에서 검증해야 합니다. 분할 화면/게임패드도 검증 대상 밖입니다.

## 검증과 설치

사용자는 공 이동·충전 세기·벽 반사를 실제 게임에서 확인했습니다. 이후 로그에서 HUD 초기화 중 존재하지 않는 Lua UI 메서드 호출 오류를 확인했습니다. 0.3에서 해당 호출을 제거하고 실제 게임 UI 코드로 초기화 회귀 검사를 추가했습니다. 골대 선 지정·거리 조정·회전·그림자·소유 드리블·태클과 테스트 구역은 소스/네이티브 검사 대상이며 **업데이트 후 실기 검증 전**입니다.

`scripts/test.ps1`은 설치된 Kahlua에서 물리·골 판정·서버 권한·전환·입력·배치·HUD·카메라 경계·모션을 검증합니다. Java 검사는 설치된 API와 애니메이션 선택을 확인하고 실제 마우스 입력 클래스의 누름 캡처/다음 클릭 복원을 실행합니다. 게임/네트워크 부트스트랩 검사는 실제 접속 증거가 아닙니다.
