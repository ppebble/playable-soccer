# Playable Soccer

Project Zomboid B42.21+용 길거리 축구 개발 버전입니다. 공을 소모하지 않고 계속 차며, 직접 지정한 두 골문으로 득점할 수 있습니다.

## 조작

1. 기본 `Base.SoccerBall`을 인벤토리에서 우클릭하여 **스포츠용 축구공으로 전환**합니다. 전용 타입은 `PlayableSoccer.SportsSoccerBall`입니다. 상태·즐겨찾기·사용자 이름·메타데이터를 유지하며 역전환도 가능합니다.
2. 스포츠 공을 주 인벤토리에 넣고 **축구 연습 시작**을 선택합니다. 3D 바닥 아이템 표시 옵션이 켜져 있어야 합니다.
3. **좌클릭 길게 누르기 → 떼기: 땅볼**, **우클릭 길게 누르기 → 떼기: 로빙**. 커서 방향으로 차며 충전량이 힘을 정합니다. 상단 중앙에 충전 게이지를 표시합니다.
4. **Esc**는 충전 중에는 취소, 충전 중이 아니면 축구 조작 해제입니다. 축구가 처리한 Esc는 기본 게임 메뉴에 전달하지 않으며, 조작 해제 후 다음 Esc는 기본 메뉴를 엽니다. 이후 우클릭으로 일반 메뉴를 열 수 있습니다. 공은 그대로 남습니다.
5. 월드 우클릭 메뉴에서 근처 공으로 다시 플레이하거나 소유자가 자신의 연습을 종료할 수 있습니다. 다른 플레이어도 같은 공을 찰 수 있습니다.

축구 조작 중 해당 마우스 클릭만 기본 공격·조준 입력에서 제외합니다. 게임 키 설정이나 전역 조작 함수를 바꾸지 않습니다. UI·다른 작업에서는 기본 입력을 유지합니다. 달리기/전력질주 중 선택한 지면 공에 0.8칸 이내로 닿으면 진행 방향으로 약 1.5칸 밀어줍니다. 자동 터치는 0.4초 간격이며 충전 중에는 작동하지 않습니다. 헤딩·손으로 공 운반은 없습니다.

## 골문과 경기

소유자는 Esc로 조작을 해제한 뒤 월드 우클릭 → **골대 두 줄 지정**을 선택합니다. 차례로 1번 골대 선의 시작·끝, 2번 골대 선의 시작·끝을 클릭합니다. 총 네 번 클릭하며 첫 점 이후 선과 길이를 미리 표시합니다. 중앙 재개 지점은 두 골대 선의 중점 사이로 자동 결정됩니다. 배치 중 우클릭/Esc로 취소합니다.

- 골문 너비 2~10칸. 서로 마주보는 두 골문을 지정하고 중앙은 각 골문 안쪽으로 최소 2칸 이상 둡니다. 모든 지정점은 소유자 40칸 이내의 로딩된 빈 바닥이어야 합니다.
- 골문은 색상별 지면 선과 기둥 표식으로 보입니다. 현재는 투영된 표시이며 실물 골대·그물 모델은 없습니다.
- 팀 선택도 조작 해제 후 우클릭 메뉴에서 합니다. 팀을 선택하면 공 조작으로 돌아갑니다. A 골문을 통과하면 B팀 득점, 반대도 동일합니다.
- 점수판과 골 메시지는 **화면 상단 중앙**에 표시합니다. 공 전체가 경기장 쪽에서 골문 너비·높이 안으로 넘어가야 득점합니다. 높이 제한은 .8층 단위입니다.
- 득점 후 2초간 멈췄다가 **같은 공**을 중앙으로 돌려 재개합니다. 소유자의 공 중앙 복귀 메뉴도 있습니다. 공 복귀는 점수를 초기화하지 않습니다. 골문 재지정은 새 경기로 점수를 초기화합니다.
- 벽에 맞아도 계속 플레이합니다. 오프사이드·파울·스로인·AI 골키퍼는 없습니다. 팀 명단은 간단한 소속 정보이며 인원 균형이나 포지션을 강제하지 않습니다.

## 공과 표시

공은 수명·바운스 횟수·정지·소유자 연결 해제로 사라지지 않습니다. 마찰과 충돌 감쇠로 멈춘 후 다시 찰 수 있습니다. 최소 충전은 약 1.5칸, 최대 충전은 평지에서 약 18~20칸으로 줄였습니다. 벽에 부딪히면 더 짧아지며, 다시 차면 새로운 킥으로 취급합니다. 최대 서버 32개/소유자 1개 연습 공을 허용하며 연습 중 해당 아이템 역전환을 막습니다.

서버가 공 물리와 득점·아이템 검증을 소유합니다. 3D 공은 새 표시 전용 아이템의 분리된 `IsoWorldInventoryObject`로 그리며 월드/타일 목록·저장·줍기 대상으로 등록하지 않습니다. 기본 축구공 모델을 참조하며 Throwing Weapons 코드나 자산을 포함하지 않습니다. 이동 거리에 따라 모델이 회전하고 멈추면 회전도 멈춥니다. 바닥에 고정된 그림자와 선택한 공의 공중 높이 안내점을 표시합니다. 회전은 네이티브 렌더 캐시의 무한 증가를 피하도록 제한된 각도 단계로 그립니다.

킥에는 전투 이벤트가 없는 별도 애니메이션 노드가 적용됩니다. **현재는 기본 게임의 아래로 내딛는 발동작을 다리에만 적용한 임시 모션**이며 새로 제작한 전방 축구 킥은 아닙니다. 이동을 잠그지 않고 걷기 시작하면 취소됩니다. 발 접촉과 공 출발의 정밀 일치·원격 재생은 실기 확인이 필요합니다.

## Viewpoint 준비 및 한계

골문과 물리는 월드 좌표로 저장합니다. 모든 클릭/화면 투영은 `PSProjection` 연결부를 통하며 추후 카메라 어댑터로 교체할 수 있습니다. **현재 Viewpoint 호환은 활성화하지 않았습니다.** Viewpoint가 감지되고 어댑터가 없으면 잘못된 좌표로 차거나 배치하지 않도록 해당 입력을 막습니다. 이후 마우스 레이캐스트, 층/높이, 3D 공·표식 렌더 순서, HUD 및 우클릭 충돌을 함께 검증해야 합니다. 좌표 함수만 연결했다고 호환 완료로 간주하지 않습니다.

유지 범위는 현재 서버 실행 세션이며 저장/재시작 후 공 위치 복원은 없습니다. 벽·닫힌 문/창문·고체 타일은 보수적으로 충돌하며 정밀 가구/차량/공 반지름 충돌, 천장, 공중 층 이동은 아직 없습니다. 로딩 안 된 지역과 바닥 없는 곳 앞에서는 정지합니다. 로빙은 열린 공간에서 검증해야 합니다. 분할 화면/게임패드도 검증 대상 밖입니다.

## 검증과 설치

사용자는 공 이동·충전 세기·벽 반사를 실제 게임에서 확인했습니다. 이후 로그에서 HUD 초기화 중 존재하지 않는 Lua UI 메서드 호출 오류를 확인했습니다. 0.3에서 해당 호출을 제거하고 실제 게임 UI 코드로 초기화 회귀 검사를 추가했습니다. 골대 선 지정·거리 조정·회전·그림자·자동 드리블 변경은 소스/네이티브 검사 대상이며 **업데이트 후 실기 검증 전**입니다.

`scripts/test.ps1`은 설치된 Kahlua에서 물리·골 판정·서버 권한·전환·입력·배치·HUD·카메라 경계·모션을 검증합니다. Java 검사는 설치된 API와 애니메이션 선택을 확인하고 실제 마우스 입력 클래스의 누름 캡처/다음 클릭 복원을 실행합니다. 게임/네트워크 부트스트랩 검사는 실제 접속 증거가 아닙니다.

`scripts/package.ps1`은 `.stage` 패키지를 만들고 `-Install`은 현재 사용자 `Zomboid/mods/PlayableSoccer`에 설치하여 파일 해시를 비교합니다. 기존 설치본은 `.build/backups`에 보관합니다. 기존 `gael-test` 모드 항목을 그대로 사용하며 실행 중인 게임/서버에는 재시작 후 적용됩니다. 서버 프리셋·저장 파일·Steam 공개 상태는 변경하지 않습니다.
