# Playable Soccer

Project Zomboid B42.21+용 독립 축구공 연습 프로토타입입니다. 현재 단계는 공의 지속 물리와 조작이며 팀, 득점, 경기장 및 AI는 포함하지 않습니다.

## 사용

1. 인벤토리의 기본 `Base.SoccerBall`을 우클릭하여 **스포츠용 축구공으로 전환**합니다. 전용 아이템은 `PlayableSoccer.SportsSoccerBall`입니다. 다시 일반 공으로 전환할 수 있으며 상태, 즐겨찾기, 사용자 이름 및 메타데이터를 유지합니다.
2. 스포츠용 축구공을 **주 인벤토리**에 넣고 우클릭 메뉴에서 연습을 시작합니다. 공 아이템을 소모하지 않습니다.
3. 공 근처에서 마우스로 방향을 정하고 **좌클릭을 눌러 충전, 떼면 킥**합니다. 짧은 킥으로 공을 몰고 갈 수 있습니다. 자동 드리블이나 손으로 집어 운반하는 기능은 없습니다.
4. 충전 중 우클릭으로 취소합니다. 월드 우클릭 메뉴에서 근처 공의 조작에 참여하거나 조작을 해제합니다. 다른 플레이어도 같은 공을 찰 수 있습니다.
5. 소유자는 월드 우클릭 메뉴에서 자신의 연습을 종료할 수 있습니다. 조작 해제, 멀어짐, 공의 정지 및 연결 종료 자체는 공을 없애지 않습니다. 연습 중에는 해당 아이템을 일반 공으로 되돌릴 수 없습니다.

공은 바운스 횟수나 수명으로 제거되지 않습니다. 지면 마찰과 반사 시 감쇠로 멈추며 다시 차면 움직입니다. 기본 킥은 땅볼이고 로빙/칩슛 입력은 아직 없습니다. 서버당 최대 32개, 사용자당 최대 한 개의 연습 공을 허용합니다.

게임의 **3D 바닥 아이템 표시 옵션**이 켜져 있어야 합니다. 옵션이 꺼져 있으면 시작/킥을 막고 안내합니다. 모델 로딩 실패 여부는 현재 렌더 API가 반환하지 않으므로 실제 화면 확인이 필요합니다.

## 구현 경계

- 서버가 위치·속도·충돌·시작/종료를 소유하고 아이템 ID, 소유권, 거리, 층, 생존 상태, 요청 빈도를 검증합니다.
- 물리 공은 일반 바닥 인벤토리 아이템이 아닙니다. 클라이언트는 신규 표시 전용 아이템으로 분리된 `IsoWorldInventoryObject`를 만들어 기본 게임의 축구공 모델을 그립니다. 월드/타일 목록 등록, 네트워크 전송 및 저장을 하지 않습니다. 원래 인벤토리 아이템을 렌더 프록시에 전달하지 않습니다.
- 기본 게임 모델을 참조하며 Throwing Weapons 의존성이나 해당 모드의 코드/자산을 포함하지 않습니다.
- 벽·막힌 문/창문·고체 타일에 대해 보수적인 타일 충돌을 사용합니다. 공 반지름, 정밀 가구 모양, 벽 높이, 연속 회전, 계단을 통한 층 이동은 아직 지원하지 않습니다. 로딩 안 된 타일이나 바닥 없는 지형 앞에서는 안전 정지합니다.
- 유지 범위는 현재 서버 실행 세션입니다. **저장/서버 재시작 후 공 위치 복원은 없습니다.** 인벤토리 스포츠 공은 남으므로 새 세션에서 다시 시작할 수 있습니다.
- 클라이언트는 서버 표본 사이를 보간합니다. 실제 렌더 순서, 벽/인물 가림, 축구공 크기, 타일 경계 깜박임 및 멀티 지연 상황은 게임 안에서 별도 검증해야 합니다. 분할 화면/게임패드는 지원 대상으로 검증하지 않았습니다.

## 검증과 설치

`scripts/test.ps1`은 설치된 게임의 Kahlua VM에서 물리, 서버 검증, 아이템 전환 및 클라이언트 입력 테스트를 실행하고 실제 Java API와 아이템 정의를 확인합니다. 테스트 부트스트랩은 게임/네트워크를 대체하므로 통과가 실기 증거는 아닙니다. `LuaHarness.java`는 같은 작성자의 Playable Baseball 테스트 실행기를 재사용합니다.

`scripts/package.ps1`은 `.stage`에 패키징합니다. `scripts/package.ps1 -Install`은 현재 사용자 `Zomboid/mods/PlayableSoccer`에 설치하고 모든 파일 해시를 비교합니다. 기존 동일 모드 설치는 저장소 `.build/backups`에 보관합니다. 서버 프리셋과 저장 파일을 변경하거나 Steam에 업로드하지 않습니다.

실기 확인 순서: 전환/역전환 → 시작/종료 → 짧은 킥/강한 킥 → 여러 벽 반사 → 정지 후 재킥 → 문/코너/미로딩 경계 → 두 클라이언트가 같은 공 차기 → UI/채팅/죽음/재접속 중 입력과 중복 아이템 확인.
